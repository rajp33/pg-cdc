# pg-cdc Milestone 2 (Deliver) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver every change at least once to Amazon SNS (or the `stdout` and `discard` sinks), in order per order key, through lanes with retries, and acknowledge the slot only from transactions whose every event the sink has confirmed, with the reader paused at a byte bound while status updates keep flowing.

**Architecture:** The session builds each envelope as in milestone 1, then derives its order key (an XXH3-128 hash of a canonical JSON array), encodes it once into an `Outbound` (body plus SNS-style attributes), registers it with the ack tracker, which returns a `Ticket`, and dispatches it to lane `order_key_id mod lanes`. Each lane is a tokio task that holds per-key queues, sends at most one event per key at a time in batches that respect the sink's limits (lingering up to 5 ms), backs a failing key off from 100 ms to 30 s with full jitter while other keys flow, and reports a `Settled` value that only a `Delivered` outcome can produce. The session loop owns the ack tracker without locks: it settles reports, confirms the advancing LSN to the transport (whose own timer sends the status updates), stops reading the socket while in-flight bytes are at `delivery.max_inflight_bytes`, and on shutdown drains for 5 s, stops the lanes, sends the final status update and exits 0 whatever the sink is doing.

**Tech Stack:** Rust 1.99.0 (edition 2024), tokio 1.53 (`JoinSet`, `Semaphore`, `mpsc`, `watch`), async-trait 0.1.92, bytes 1.12.1, twox-hash 2.1.5 (`xxhash3_128`), aws-sdk-sns 1.116 and aws-config 1.12 over rustls (ring), aws-sdk-sqs 1.114 (tests), testcontainers 0.28 with moto 5.2.4 (R3), proptest 1.12, cargo-nextest, mise.

**Spec:** `docs/superpowers/specs/2026-10-14-pg-cdc-design.md` (binding). This plan implements spec §19 item 2 (order keys, lanes, the ack tracker, the status task, backpressure, the `Sink` trait, the `sns` and `discard` sinks, and retries) using §5, §7.3, §8, §9, §10.1, §11.1, §11.2, §12.5 (steps 1, 2, 3 and 5, without parking or the leader record), §14 (O2, A1–A4), §15 and §17.1 (log destination). It also fixes the shutdown defect carried from milestone 1 (Task 7).

## Rulings

Each ruling is "decision — why — cost if wrong". Numbering continues from milestone 1.

- **R28. The status task of §9.3 is the transport worker's timer, fed by the session loop.** The transport (M1 Task 3) already sends a status update every `status_interval` and immediately on a reply request, whatever the consumer does, and pins A4. Milestone 2 calls `ReplicationStream::confirm` on every settlement, commit and keepalive from the session loop, which keeps polling settlements while the reader is paused (Task 7, Task 8). A second status task would duplicate the transport's. Cost if wrong: if a later milestone needs status updates while the session loop itself is blocked, `confirm` moves into a separate task that owns the tracker.
- **R29. The ack tracker lives in the session loop, without locks.** Lanes report `Settled` values over an unbounded channel. A `Settled` can only be produced by `Ticket::settle` from an `Outcome::Delivered` (A1, §14.6); milestone 3 adds a second constructor from a park confirmation. `AckTracker::settle` takes the `Settled` by value, so one ticket settles once (the narrow `#[expect(clippy::needless_pass_by_value)]` in Task 4 records this). Cost if wrong: none for correctness; settlement latency is one loop turn.
- **R30. Backpressure counts encoded body bytes, admits below the bound, and shrinks the transport channel.** In-flight bytes are the `body` lengths of tracked, unsettled events (§9.4, "measured on encoded envelopes"). The session reads the next transport event only while in-flight bytes are below `delivery.max_inflight_bytes`, so a single event larger than the bound still flows alone instead of deadlocking. `session::REPLICATION_BUFFER` drops from 1024 to 64 events, because the transport channel is the only other buffer and R25 said this bound replaces it. Cost if wrong: memory exceeds the bound by at most one event plus 64 raw messages.
- **R31. Lane inboxes are unbounded; dispatch never blocks.** The byte bound (R30) bounds what they hold, and a blocking dispatch could deadlock the loop that also settles. Cost if wrong: none while R30 holds.
- **R32. Linger is measured from the arrival of the oldest ready event.** A batch that is not full is sent once the event at the front of the ready queue is 5 ms old, so a backlog (for example under `order_by: pipeline`) never lingers between round trips, while a trickle waits at most 5 ms for companions. Cost if wrong: smaller batches under light traffic.
- **R33. Milestone 2 has no StateStore: retries never park, and dead events block their key in memory.** `delivery.park_after` and `delivery.max_parked_events` belong to milestone 3 and are rejected by the strict config (R12). A retryable outcome retries forever with the §10.1 backoff. A terminal outcome, or an event whose encoded size exceeds the sink's `max_message_bytes` (§7.5 without a PayloadStore), blocks its order key exactly as a dead event would (§10.4): never sent again, never settled, logged at error once; the slot stops before it until milestone 3 parks it, and a restart replays it. Cost if wrong: a poison message stalls acknowledgement until milestone 3; nothing is lost or skipped.
- **R34. Sink failures never end a session; the carried shutdown defect is fixed structurally.** Sinks report failures only as outcomes, so `SessionError::Sink` is removed and the stdout sink maps write errors (EPIPE included) to `Retryable`. Shutdown (§12.5 without parking or the leader record) stops reading, waits up to `DRAIN_TIMEOUT` (5 s, still a constant until milestone 4 adds `leadership.drain_timeout`) for in-flight events to settle, stops the lanes, calls `ReplicationStream::stop` (final status update at the confirmed LSN, then CopyDone) and returns `Ok`, so `pg-cdc run` exits 0; whatever did not settle is never confirmed and replays. The stdout sink owns its writer in a task and writes each batch with one `write_all`, so no lock is held across `.await` and concurrent batches never interleave lines. Cost if wrong: `pg-cdc run | head` keeps retrying until it is signalled instead of exiting 1.
- **R35. Lanes, the tracker and the sink-concurrency semaphore are per session; the sink is per process.** A reconnect drops the old lanes (aborting in-flight sends) and the server replays from the confirmed LSN with the same ids, so duplicates are possible and loss is not. R22's `reset_pending` has nothing left to reset and is removed with the M1 `StdoutSink`. Cost if wrong: none.
- **R36. `Sink` has `std::fmt::Debug` as a supertrait, and `SinkError` is a newtype over a message.** The spec's signature has only `Send + Sync`; the supertrait lets every struct holding `Arc<dyn Sink>` derive `Debug` under `missing_debug_implementations`. Cost if wrong: one bound.
- **R37. Message attributes follow SNS types.** `schema`, `table` and `op` always; each `attribute_columns` value from `after`, or `before` when there is no `after` (§11.2). JSON numbers with at most 38 digits and no exponent are `Number`; longer numbers, numbers in exponent form (Postgres writes float values at or above 1e15 or below 1e-4 that way, and SNS rejects a Number outside 10^-128 to 10^126), booleans, arrays and objects are `String` (compact JSON text); `null`, empty strings and absent columns are omitted, because SNS rejects an empty value for the whole batch (moto probe on 2026-10-14: `InvalidParameter` for the request). Config allows at most 7 attribute columns (10 minus the three fixed ones), distinct, not `schema`, `table` or `op`, and valid SNS attribute names. Cost if wrong: a consumer filtering on a large number sees a String attribute.
- **R38. SNS sink details.** Entry ids are batch indices. A request-level failure (throttling, 5xx, timeout, credentials, missing topic) makes every entry `Retryable`; a failed entry with `SenderFault=true` is `Terminal`, otherwise `Retryable`; an entry missing from the response is `Retryable`. `BatchRequestTooLong` resends the entries one at a time, and a single entry still too long is `Terminal`. `MaximumMessageSize` is read when present (moto omits it), clamped to 1 MiB, defaults to 256 KiB, and is also the batch byte limit, which the §21 risk leaves unverified for 1 MiB topics; the one-at-a-time fallback covers a wrong guess. SDK retries are disabled (§11.1) and each call has a 15 s operation timeout. `send` before `preflight` is `Retryable`. Cost if wrong: retry timing or batch sizes only.
- **R39. `sink.fair_queue_group: column:<name>` reads its value from that column's attribute.** The column must be in `attribute_columns` (§11.2). A value that is not 1 to 128 printable ASCII characters without spaces (the SNS `MessageGroupId` rules) is sent without a group, and on a FIFO topic the setting is ignored with a warning because the order key is the group. Cost if wrong: such messages lose fairness grouping, never delivery.
- **R40. Sink preflight gates the session.** `pg-cdc run` retries `Sink::preflight` with the reconnect backoff (1 s to 30 s) until it succeeds or a signal arrives, and only then opens the replication connection, so a task with a misconfigured sink never takes the slot (§11.1, §13.2). `pg-cdc health` is milestone 4. Cost if wrong: none.
- **R41. The SNS sink is unit-tested through a private `SnsApi` seam.** Production uses the AWS client; unit tests use a fake, because moto neither enforces the aggregate batch limit nor returns per-entry failures (probe on 2026-10-14). Moto integration tests (R3) cover the wire path: standard and FIFO topics through SQS subscriptions, attributes, group and deduplication ids, a missing topic. Cost if wrong: one trait.
- **R42. The order key hash is XXH3-128 with seed 0 from twox-hash 2.1.5.** xxhash-rust is BSL-1.0, which `deny.toml` does not allow. The golden id in Task 1 was checked against `xxh128sum` from the reference xxHash 0.8. Cost if wrong: every order key id changes, which matters only once parked queues exist (milestone 3).
- **R43. Delivery settings are validated.** `delivery.lanes` is 1 to 4096; `delivery.max_inflight_bytes` is above zero; sizes are an integer followed by `B`, `KiB`, `MiB` or `GiB`; a list from the environment is comma-separated (`PGCDC__SINK__ATTRIBUTE_COLUMNS=tenant_id,region`). Cost if wrong: a config edit.
- **R44. The stream test harness defaults to `order_by: pipeline` with one lane.** The milestone 1 suites keep asserting stream order unchanged; milestone 2 tests set `order_by: key` and several lanes explicitly. Cost if wrong: none.
- **R45. Runtime fail-stop checks for O2 and A2 (§14.6).** O2: every event reaching a lane must have a larger id than the one before it (dispatch is in stream order), else `LaneError::OutOfOrder` ends the session as fatal. A2: a commit whose end LSN is below the previous commit's is `AckError::CommitOutOfOrder`, fatal. Cost if wrong: a halt that a restart replays.
- **R46. Logs go to stdout for the `sns` and `discard` sinks** (§17.1), and to stderr for `stdout` (R8). Task 9's CLI tests pin both. Cost if wrong: one match arm.
- **R47. `Lanes` uses `tokio::task::JoinSet`, whose drop aborts every lane.** A session that ends on an error drops its lanes without waiting; a clean shutdown awaits `Lanes::shutdown`. Cost if wrong: none.
- **R48. Only fallible test helpers return `Result`.** The Global Constraint on helpers in `crates/*/tests` is about never panicking outside a `#[test]` function; infallible helpers and trait impls (the harness's `config`, `spawn_with`, `set_mode`, `TestSink::send`, the CLI's `moto_env`, and milestone 1's `params`) return their value directly, because wrapping an infallible value in `Result` only adds `?` noise. Cost if wrong: a reviewer asks for `Result` wrappers on infallible helpers.
- **R49. `supervise` and `supervisor::preflight` share one cancellable backoff sleep.** Both loops back off and stop on shutdown, so Task 9 extracts `sleep_unless_cancelled(delay, shutdown) -> bool` instead of repeating the `select!` block verbatim in `preflight`. Cost if wrong: one private helper.
- **R50. `Running::skip_events` reuses `Running::next_event`.** It discards parsed events instead of repeating the receive-with-timeout block; parsing 30,000 small envelopes costs well under a second. Cost if wrong: a slightly slower backpressure test.

## Review Focus

The five inputs or failure modes the spec implies but its listed tests do not exercise, most likely to bite first. Each is pinned by a test in the owning task.

1. **The consumer of stdout goes away (EPIPE on `pg-cdc run | jq` after Ctrl-C), or the sink is still failing when SIGTERM arrives.** Expected: the drain gives up after 5 s, the final status update reports the last confirmed LSN, the process exits 0, and the undelivered transaction replays on the next run. Tests: Task 7 `shutdown_with_a_failing_sink_stops_cleanly_and_replays_the_undelivered_event`, Task 9 `sigterm_after_stdout_closes_exits_cleanly_and_confirms_only_what_was_delivered`.
2. **A single huge transaction (tens of MB) arrives while the sink is slow or down.** Expected: the reader stops reading at the in-flight bound, status updates keep the walsender connection alive past `wal_sender_timeout`, and everything flows once the sink recovers. Test: Task 8 `a4_backpressure_pauses_reading_while_status_updates_keep_the_connection`.
3. **One order key keeps failing while others succeed, so a later transaction settles before an earlier one.** Expected: other keys keep flowing, but the slot never passes the earlier unsettled transaction. Tests: Task 5 `a_retryable_outcome_backs_off_only_its_key`, Task 4 `a2_a_later_transaction_never_confirms_past_an_earlier_unsettled_one`, Task 7 `a2_the_slot_waits_for_an_earlier_transaction_held_by_a_retrying_key`.
4. **Row values SNS rejects as attributes or group ids: empty strings, nulls, numbers beyond 38 digits, booleans, JSON, values with spaces.** Expected: such values never poison a batch; they are omitted or sent as `String`, and an invalid fair-queue group is dropped. Tests: Task 2 `attribute_columns_are_typed_for_sns_and_omitted_when_null_empty_or_absent`, Task 3 `standard_entries_take_a_valid_fair_queue_group_from_their_attributes`, Task 9 `rejects_invalid_sns_settings`.
5. **A misconfigured topic, or a row larger than the topic's message limit.** Expected: a missing topic keeps preflight retrying without taking the slot; an oversize event is never sent and blocks only its own key; a batch SNS rejects as too long is retried one entry at a time. Tests: Task 9 `a_missing_sns_topic_keeps_preflight_retrying_without_taking_the_slot`, Task 5 `an_event_larger_than_the_sink_message_limit_is_never_sent`, Task 3 `a_batch_rejected_as_too_long_is_resent_one_entry_at_a_time`.

```rust
use std::fmt;
use std::str::FromStr;

use serde_json::Value;
use twox_hash::XxHash3_128;

use crate::event::Envelope;

#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub enum OrderBy {
    #[default]
    Key,
    Table,
    Column(String),
    Pipeline,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
#[error("{0:?} is not key, table, pipeline or column:<name>")]
pub struct InvalidOrderBy(pub String);

impl FromStr for OrderBy {
    type Err = InvalidOrderBy;

    fn from_str(text: &str) -> Result<Self, Self::Err> {
        match text {
            "key" => Ok(Self::Key),
            "table" => Ok(Self::Table),
            "pipeline" => Ok(Self::Pipeline),
            _ => match text.strip_prefix("column:") {
                Some(name) if !name.is_empty() => Ok(Self::Column(name.to_owned())),
                _ => Err(InvalidOrderBy(text.to_owned())),
            },
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct OrderKeyId(u128);

impl OrderKeyId {
    pub fn of(canonical: &[u8]) -> Self {
        Self(XxHash3_128::oneshot(canonical))
    }

    pub fn lane(self, lanes: usize) -> usize {
        let lanes = u128::try_from(lanes.max(1)).unwrap_or(u128::MAX);
        usize::try_from(self.0 % lanes).unwrap_or(0)
    }
}

impl fmt::Display for OrderKeyId {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "{:032x}", self.0)
    }
}

pub fn column_value<'a>(envelope: &'a Envelope, column: &str) -> Option<&'a Value> {
    envelope
        .after
        .as_ref()
        .or(envelope.before.as_ref())?
        .get(column)
        .filter(|value| !value.is_null())
}

pub fn canonical_order_key(order_by: &OrderBy, envelope: &Envelope) -> Value {
    let table = || {
        vec![
            Value::String(envelope.schema.clone()),
            Value::String(envelope.table.clone()),
        ]
    };
    let parts = match order_by {
        OrderBy::Key => {
            let mut parts = table();
            if let Some(key) = &envelope.key {
                parts.extend(key.values().cloned());
            }
            parts
        }
        OrderBy::Table => table(),
        OrderBy::Column(name) => match column_value(envelope, name) {
            Some(value) => vec![value.clone()],
            None => table(),
        },
        OrderBy::Pipeline => Vec::new(),
    };
    Value::Array(parts)
}

pub fn order_key(order_by: &OrderBy, envelope: &Envelope) -> OrderKeyId {
    OrderKeyId::of(
        canonical_order_key(order_by, envelope)
            .to_string()
            .as_bytes(),
    )
}
```

use async_trait::async_trait;
use tokio::io::{AsyncWrite, AsyncWriteExt};
use tokio::sync::{mpsc, oneshot};

use super::{Outbound, Outcome, Sink, SinkCapabilities, SinkError};

pub const STDOUT_CAPABILITIES: SinkCapabilities = SinkCapabilities {
    max_batch_messages: 1024,
    max_batch_bytes: 1 << 20,
    max_message_bytes: usize::MAX,
};

type WriteRequest = (Vec<u8>, oneshot::Sender<std::io::Result<()>>);

#[derive(Debug)]
pub struct StdoutSink {
    requests: mpsc::Sender<WriteRequest>,
}

impl StdoutSink {
    pub fn stdout() -> Self {
        Self::new(tokio::io::stdout())
    }

    pub fn new<W: AsyncWrite + Unpin + Send + 'static>(writer: W) -> Self {
        let (requests, receiver) = mpsc::channel(1);
        tokio::spawn(write_lines(writer, receiver));
        Self { requests }
    }

    async fn write(&self, lines: Vec<u8>) -> Result<(), SinkError> {
        let (reply, written) = oneshot::channel();
        self.requests
            .send((lines, reply))
            .await
            .map_err(|_| SinkError("the stdout writer has stopped".to_owned()))?;
        written
            .await
            .map_err(|_| SinkError("the stdout writer has stopped".to_owned()))?
            .map_err(|error| SinkError(format!("cannot write to stdout: {error}")))
    }
}

async fn write_lines<W: AsyncWrite + Unpin>(
    mut writer: W,
    mut requests: mpsc::Receiver<WriteRequest>,
) {
    while let Some((lines, reply)) = requests.recv().await {
        let written = match writer.write_all(&lines).await {
            Ok(()) => writer.flush().await,
            Err(error) => Err(error),
        };
        let _ = reply.send(written);
    }
}

#[async_trait]
impl Sink for StdoutSink {
    fn capabilities(&self) -> SinkCapabilities {
        STDOUT_CAPABILITIES
    }

    async fn preflight(&self) -> Result<(), SinkError> {
        Ok(())
    }

    async fn send(&self, batch: &[Outbound]) -> Vec<Outcome> {
        let size = batch.iter().map(|outbound| outbound.body.len() + 1).sum();
        let mut lines = Vec::with_capacity(size);
        for outbound in batch {
            lines.extend_from_slice(&outbound.body);
            lines.push(b'\n');
        }
        let outcome = match self.write(lines).await {
            Ok(()) => Outcome::Delivered,
            Err(error) => Outcome::Retryable(error),
        };
        vec![outcome; batch.len()]
    }
}

#[async_trait]

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
struct Topic {
    fifo: bool,
    max_message_bytes: usize,
}

impl Topic {
    fn from_attributes(attributes: &HashMap<String, String>) -> Self {
        let fifo = attributes
            .get("FifoTopic")
            .is_some_and(|value| value == "true");
        let max_message_bytes = attributes
            .get("MaximumMessageSize")
            .and_then(|value| value.parse::<usize>().ok())
            .filter(|bytes| *bytes > 0)
            .map_or(SNS_DEFAULT_MESSAGE_BYTES, |bytes| {

            });
        Self {
            fifo,

        }
    }
}

#[derive(Debug)]
pub struct SnsSink {
    api: Box<dyn SnsApi>,
    topic_arn: String,
    fair_queue_group: Option<String>,
    topic: OnceLock<Topic>,
}

impl SnsSink {
    pub fn new(client: Client, topic_arn: String, fair_queue_group: Option<String>) -> Self {
        Self::with_api(Box::new(AwsSns(client)), topic_arn, fair_queue_group)
    }

    pub async fn from_environment(
        topic_arn: String,
        region: Option<String>,
        fair_queue_group: Option<String>,
    ) -> Self {
        let http_client = aws_smithy_http_client::Builder::new()
            .tls_provider(Provider::Rustls(CryptoMode::Ring))
            .build_https();
        let mut loader = aws_config::defaults(BehaviorVersion::latest())
            .http_client(http_client)
            .retry_config(RetryConfig::disabled())
            .timeout_config(
                TimeoutConfig::builder()
                    .operation_timeout(SNS_OPERATION_TIMEOUT)
                    .build(),
            );
        if let Some(region) = region {
            loader = loader.region(Region::new(region));
        }
        Self::new(
            Client::new(&loader.load().await),
            topic_arn,
            fair_queue_group,
        )
    }

    fn with_api(api: Box<dyn SnsApi>, topic_arn: String, fair_queue_group: Option<String>) -> Self {
        Self {
            api,
            topic_arn,
            fair_queue_group,
            topic: OnceLock::new(),
        }
    }

    fn entry(&self, index: usize, outbound: &Outbound, topic: Topic) -> Result<Entry, SinkError> {
        let message = std::str::from_utf8(&outbound.body)
            .map_err(|error| SinkError(format!("event {} is not UTF-8: {error}", outbound.id)))?;
        let (group, dedupe) = if topic.fifo {
            (
                Some(outbound.order_key.to_string()),
                Some(outbound.id.to_string()),
            )
        } else {
            let group = self
                .fair_queue_group
                .as_deref()
                .and_then(|column| outbound.attribute(column))
                .map(AttributeValue::as_str)
                .filter(|value| valid_group_id(value))
                .map(str::to_owned);
            (group, None)
        };
        Ok(Entry {
            id: index.to_string(),
            message: message.to_owned(),
            attributes: outbound.attributes.clone(),
            group,
            dedupe,
        })
    }

    async fn publish(&self, entries: &[Entry]) -> Vec<(usize, Outcome)> {
        if entries.is_empty() {
            return Vec::new();
        }
        match self.api.publish_batch(&self.topic_arn, entries).await {
            Err(PublishFailure::TooLong(message)) if entries.len() > 1 => {
                tracing::warn!(
                    entries = entries.len(),
                    %message,
                    "SNS rejected the batch as too long; sending its entries one at a time"
                );
                let mut outcomes = Vec::with_capacity(entries.len());
                for entry in entries {
                    let single = std::slice::from_ref(entry);
                    let result = self.api.publish_batch(&self.topic_arn, single).await;
                    outcomes.extend(results(single, result));
                }
                outcomes
            }
            result => results(entries, result),
        }
    }
}

fn valid_group_id(value: &str) -> bool {
    (1..=SNS_MAX_GROUP_ID_BYTES).contains(&value.len())
        && value.bytes().all(|byte| byte.is_ascii_graphic())
}

fn results(
    entries: &[Entry],
    result: Result<BatchResult, PublishFailure>,
) -> Vec<(usize, Outcome)> {
    let index = |id: &str| id.parse::<usize>().ok();
    let every_entry = |outcome: Outcome| {
        entries
            .iter()
            .filter_map(|entry| Some((index(&entry.id)?, outcome.clone())))
            .collect()
    };
    match result {
        Ok(batch) => {
            let mut outcomes: Vec<(usize, Outcome)> = batch
                .successful
                .iter()
                .filter_map(|id| Some((index(id)?, Outcome::Delivered)))
                .collect();
            for failure in batch.failed {
                let Some(position) = index(&failure.id) else {
                    continue;
                };
                let error = SinkError(format!("{}: {}", failure.code, failure.message));
                let outcome = if failure.sender_fault {
                    Outcome::Terminal(error)
                } else {
                    Outcome::Retryable(error)
                };
                outcomes.push((position, outcome));
            }
            outcomes
        }
        Err(PublishFailure::TooLong(message)) => every_entry(Outcome::Terminal(SinkError(message))),
        Err(PublishFailure::Request(message)) => {
            every_entry(Outcome::Retryable(SinkError(message)))
        }
    }
}

#[async_trait]
impl Sink for SnsSink {
    fn capabilities(&self) -> SinkCapabilities {
        let max = self
            .topic
            .get()
            .map_or(SNS_DEFAULT_MESSAGE_BYTES, |topic| topic.max_message_bytes);
        SinkCapabilities {
            max_batch_messages: SNS_MAX_BATCH_MESSAGES,
            max_batch_bytes: max,
            max_message_bytes: max,
        }
    }

    async fn preflight(&self) -> Result<(), SinkError> {
        let attributes = self
            .api
            .topic_attributes(&self.topic_arn)
            .await
            .map_err(|error| {
                SinkError(format!("cannot read SNS topic {}: {error}", self.topic_arn))
            })?;
        let topic = Topic::from_attributes(&attributes);
        if topic.fifo && self.fair_queue_group.is_some() {
            tracing::warn!(
                "sink.fair_queue_group is ignored on a FIFO topic, where the order key is the message group"
            );
        }
        let _ = self.topic.set(topic);
        Ok(())
    }

    async fn send(&self, batch: &[Outbound]) -> Vec<Outcome> {
        let Some(topic) = self.topic.get().copied() else {
            let error = SinkError("the SNS sink has not passed preflight".to_owned());
            return vec![Outcome::Retryable(error); batch.len()];
        };
        let mut outcomes: Vec<Option<Outcome>> = vec![None; batch.len()];
        let mut entries = Vec::with_capacity(batch.len());
        for (index, outbound) in batch.iter().enumerate() {
            match self.entry(index, outbound, topic) {
                Ok(entry) => entries.push(entry),
                Err(error) => {
                    if let Some(slot) = outcomes.get_mut(index) {
                        *slot = Some(Outcome::Terminal(error));
                    }
                }
            }
        }
        for (index, outcome) in self.publish(&entries).await {
            if let Some(slot) = outcomes.get_mut(index) {
                *slot = Some(outcome);
            }
        }
        outcomes
            .into_iter()
            .map(|outcome| {
                outcome.unwrap_or_else(|| {
                    Outcome::Retryable(SinkError("SNS returned no result for the entry".to_owned()))
                })
            })
            .collect()
    }
}

#[derive(Debug)]
struct AwsSns(Client);

#[async_trait]
impl SnsApi for AwsSns {
    async fn topic_attributes(&self, topic_arn: &str) -> Result<HashMap<String, String>, String> {
        let output = self
            .0
            .get_topic_attributes()
            .topic_arn(topic_arn)
            .send()
            .await
            .map_err(|error| DisplayErrorContext(&error).to_string())?;
        Ok(output.attributes.unwrap_or_default())
    }

    async fn publish_batch(
        &self,
        topic_arn: &str,
        entries: &[Entry],
    ) -> Result<BatchResult, PublishFailure> {
        let mut request = self.0.publish_batch().topic_arn(topic_arn);
        for entry in entries {
            request = request.publish_batch_request_entries(sdk_entry(entry)?);
        }
        match request.send().await {
            Ok(output) => Ok(BatchResult {
                successful: output
                    .successful()
                    .iter()
                    .filter_map(|entry| entry.id().map(str::to_owned))
                    .collect(),
                failed: output
                    .failed()
                    .iter()
                    .map(|entry| EntryFailure {
                        id: entry.id().to_owned(),
                        code: entry.code().to_owned(),
                        message: entry.message().unwrap_or_default().to_owned(),
                        sender_fault: entry.sender_fault(),
                    })
                    .collect(),
            }),
            Err(error) => {
                let too_long = matches!(
                    error.as_service_error(),
                    Some(PublishBatchError::BatchRequestTooLongException(_))
                );
                let message = DisplayErrorContext(&error).to_string();
                Err(if too_long {
                    PublishFailure::TooLong(message)
                } else {
                    PublishFailure::Request(message)
                })
            }
        }
    }
}

fn sdk_entry(entry: &Entry) -> Result<PublishBatchRequestEntry, PublishFailure> {
    let invalid =
        |error: aws_sdk_sns::error::BuildError| PublishFailure::Request(error.to_string());
    let mut builder = PublishBatchRequestEntry::builder()
        .id(&entry.id)
        .message(&entry.message)
        .set_message_group_id(entry.group.clone())
        .set_message_deduplication_id(entry.dedupe.clone());
    for (name, value) in &entry.attributes {
        let value = MessageAttributeValue::builder()
            .data_type(value.data_type())
            .string_value(value.as_str())
            .build()
            .map_err(invalid)?;
        builder = builder.message_attributes(name, value);
    }
    builder.build().map_err(invalid)
}

```rust
#[derive(Debug)]
pub struct Ticket {
    txn: u64,
    bytes: u64,
}

impl Ticket {
    pub fn bytes(&self) -> u64 {
        self.bytes
    }

    pub fn settle(self, outcome: &Outcome) -> Result<Settled, Self> {
        match outcome {
            Outcome::Delivered => Ok(Settled {
                txn: self.txn,
                bytes: self.bytes,
            }),
            Outcome::Retryable(_) | Outcome::Terminal(_) => Err(self),
        }
    }
}

#[derive(Debug)]
pub struct Settled {
    txn: u64,
    bytes: u64,
}

#[derive(Debug)]
struct Txn {
    seq: u64,
    end_lsn: Option<Lsn>,
    unsettled: u64,
}

#[derive(Debug)]
pub struct AckTracker {
    confirmed: Lsn,
    txns: VecDeque<Txn>,
    next_seq: u64,
    open: bool,
    last_commit: Option<Lsn>,
    inflight_events: u64,
    inflight_bytes: u64,
}

impl AckTracker {
    pub fn new(start: Lsn) -> Self {
        Self {
            confirmed: start,
            txns: VecDeque::new(),
            next_seq: 0,
            open: false,
            last_commit: None,
            inflight_events: 0,
            inflight_bytes: 0,
        }
    }

    pub fn confirmed(&self) -> Lsn {
        self.confirmed
    }

    pub fn inflight_events(&self) -> u64 {
        self.inflight_events
    }

    pub fn inflight_bytes(&self) -> u64 {
        self.inflight_bytes
    }

    pub fn is_idle(&self) -> bool {
        !self.open && self.txns.is_empty()
    }

    pub fn begin(&mut self) -> Result<(), AckError> {
        if self.open {
            return Err(AckError::AlreadyOpen);
        }
        self.txns.push_back(Txn {
            seq: self.next_seq,
            end_lsn: None,
            unsettled: 0,
        });
        self.next_seq += 1;
        self.open = true;
        Ok(())
    }

    pub fn track(&mut self, bytes: u64) -> Result<Ticket, AckError> {
        let txn = match self.txns.back_mut() {
            Some(txn) if self.open => txn,
            _ => return Err(AckError::NotOpen),
        };
        txn.unsettled += 1;
        self.inflight_events += 1;
        self.inflight_bytes = self.inflight_bytes.saturating_add(bytes);
        Ok(Ticket {
            txn: txn.seq,
            bytes,
        })
    }

    pub fn commit(&mut self, end_lsn: Lsn) -> Result<Lsn, AckError> {
        if let Some(previous) = self.last_commit
            && end_lsn < previous
        {
            return Err(AckError::CommitOutOfOrder { previous, end_lsn });
        }
        let txn = match self.txns.back_mut() {
            Some(txn) if self.open => txn,
            _ => return Err(AckError::NotOpen),
        };
        txn.end_lsn = Some(end_lsn);
        self.open = false;
        self.last_commit = Some(end_lsn);
        self.advance();
        Ok(self.confirmed)
    }

    #[expect(
        clippy::needless_pass_by_value,
        reason = "taking the Settled by value lets each one settle only once"
    )]
    pub fn settle(&mut self, settled: Settled) -> Result<Lsn, AckError> {
        let Settled { txn, bytes } = settled;
        let unknown = AckError::UnknownSettlement { txn };
        let front = self.txns.front().map_or(u64::MAX, |txn| txn.seq);
        let index = txn
            .checked_sub(front)
            .and_then(|index| usize::try_from(index).ok())
            .ok_or(unknown.clone())?;
        let entry = self.txns.get_mut(index).ok_or(unknown.clone())?;
        entry.unsettled = entry.unsettled.checked_sub(1).ok_or(unknown)?;
        self.inflight_events -= 1;
        self.inflight_bytes = self.inflight_bytes.saturating_sub(bytes);
        self.advance();
        Ok(self.confirmed)
    }

    pub fn keepalive(&mut self, wal_end: Lsn) -> Lsn {
        if self.is_idle() {
            self.confirmed = self.confirmed.max(wal_end);
        }
        self.confirmed
    }

    fn advance(&mut self) {
        while let Some(front) = self.txns.front() {
            let Some(end_lsn) = front.end_lsn else {
                break;
            };
            if front.unsettled > 0 {
                break;
            }
            self.confirmed = self.confirmed.max(end_lsn);
            self.txns.pop_front();
        }
    }
}
```

    struct ScriptedSink {
        limits: SinkCapabilities,
        script: Script,
        latency: Duration,
        attempts: Mutex<HashMap<u32, u32>>,
        batches: Mutex<Vec<Vec<Sent>>>,
        active: AtomicUsize,
        most_active: AtomicUsize,
        drop_outcomes_once: AtomicBool,
    }

    impl std::fmt::Debug for ScriptedSink {
        fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
            f.debug_struct("ScriptedSink").finish_non_exhaustive()
        }
    }

    impl ScriptedSink {
        fn new(limits: SinkCapabilities, script: Script) -> Self {
            Self {
                limits,
                script,
                latency: Duration::ZERO,
                attempts: Mutex::new(HashMap::new()),
                batches: Mutex::new(Vec::new()),
                active: AtomicUsize::new(0),
                most_active: AtomicUsize::new(0),
                drop_outcomes_once: AtomicBool::new(false),
            }
        }

        fn delivering() -> Self {
            Self::new(LIMITS, Box::new(|_, _| Outcome::Delivered))
        }

        fn batches(&self) -> Vec<Vec<u32>> {
            self.batches
                .lock()
                .unwrap()
                .iter()
                .map(|batch| batch.iter().map(|sent| sent.ordinal).collect())
                .collect()
        }

        fn sends(&self) -> Vec<Sent> {
            self.batches.lock().unwrap().concat()
        }
    }

    #[async_trait]
    impl Sink for ScriptedSink {
        fn capabilities(&self) -> SinkCapabilities {
            self.limits
        }

        async fn preflight(&self) -> Result<(), SinkError> {
            Ok(())
        }

        async fn send(&self, batch: &[Outbound]) -> Vec<Outcome> {
            let active = self.active.fetch_add(1, Ordering::SeqCst) + 1;
            self.most_active.fetch_max(active, Ordering::SeqCst);
            tokio::time::sleep(self.latency).await;
            self.active.fetch_sub(1, Ordering::SeqCst);
            let at = Instant::now();
            let mut outcomes = Vec::new();
            let mut sent = Vec::new();
            for outbound in batch {
                let ordinal = outbound.id.ordinal();
                let attempt = {
                    let mut attempts = self.attempts.lock().unwrap();
                    let count = attempts.entry(ordinal).or_insert(0);
                    *count += 1;
                    *count
                };
                let outcome = (self.script)(ordinal, attempt);
                sent.push(Sent {
                    ordinal,
                    at,
                    delivered: outcome == Outcome::Delivered,
                });
                outcomes.push(outcome);
            }
            self.batches.lock().unwrap().push(sent);
            if self.drop_outcomes_once.swap(false, Ordering::SeqCst) {
                return Vec::new();
            }
            outcomes
        }
    }

        lanes: Lanes,

        fn new(count: usize, concurrency: usize, sink: ScriptedSink) -> Self {
            let sink = Arc::new(sink);
            let (reports, receiver) = mpsc::unbounded_channel();
            let dyn_sink: Arc<dyn Sink> = sink.clone();
            let lanes = Lanes::spawn(
                count,
                &dyn_sink,
                &Arc::new(Semaphore::new(concurrency)),
                &reports,
            );
            Self {
                lanes,
                reports: receiver,
                ack: AckTracker::new(Lsn(0)),
                commits: 0,
                sink,
            }
        }

        fn send(&mut self, ordinal: u32, key: &[u8], body: usize) -> Result<(), LaneStopped> {
            self.ack.begin().unwrap();
            let ticket = self.ack.track(u64::try_from(body).unwrap()).unwrap();
            self.ack.commit(Lsn(100 + self.commits)).unwrap();
            self.commits += 1;
            self.lanes.dispatch(Pending {
                outbound: Outbound {
                    id: EventId::new(Lsn(0x10), ordinal),
                    order_key: OrderKeyId::of(key),
                    attributes: Vec::new(),
                    body: Bytes::from(vec![b'x'; body]),
                },
                ticket,
                arrived: Instant::now(),
            })
        }

        async fn settle(&mut self, count: usize) -> Lsn {
            for _ in 0..count {
                match self.reports.recv().await {
                    Some(Report::Settled(settled)) => {
                        self.ack.settle(settled).unwrap();
                    }
                    other => panic!("expected a settlement, got {other:?}"),
                }
            }
            self.ack.confirmed()
        }

        async fn quiet_for(&mut self, window: Duration) -> bool {
            tokio::time::timeout(window, self.reports.recv())
                .await
                .is_err()
        }
    }

use std::cmp::Reverse;
use std::collections::hash_map::Entry;
use std::collections::{BinaryHeap, HashMap, VecDeque};
use std::sync::Arc;
use std::time::Duration;

use tokio::sync::{Semaphore, mpsc};
use tokio::task::JoinSet;
use tokio::time::Instant;

use crate::ack::{Settled, Ticket};
use crate::event::EventId;
use crate::order::OrderKeyId;
use crate::sink::{Outbound, Outcome, Sink, SinkCapabilities, SinkError};
use crate::supervisor::Backoff;

pub const LINGER: Duration = Duration::from_millis(5);
pub const RETRY_BASE: Duration = Duration::from_millis(100);
pub const RETRY_CAP: Duration = Duration::from_secs(30);

#[derive(Debug)]
pub struct Pending {
    pub outbound: Outbound,
    pub ticket: Ticket,
    pub arrived: Instant,
}

#[derive(Debug)]
pub enum Report {
    Settled(Settled),
    Fatal(LaneError),
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum LaneError {
    #[error("event {id} reached lane {lane} after event {previous}")]
    OutOfOrder {
        lane: usize,
        previous: EventId,
        id: EventId,
    },
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, thiserror::Error)]
#[error("lane {0} has stopped")]
pub struct LaneStopped(pub usize);

#[derive(Debug)]
pub struct Lanes {
    inboxes: Vec<mpsc::UnboundedSender<Pending>>,
    tasks: JoinSet<()>,
}

impl Lanes {
    pub fn spawn(
        count: usize,
        sink: &Arc<dyn Sink>,
        permits: &Arc<Semaphore>,
        reports: &mpsc::UnboundedSender<Report>,
    ) -> Self {
        let capabilities = sink.capabilities();
        let mut tasks = JoinSet::new();
        let inboxes = (0..count.max(1))
            .map(|index| {
                let (inbox, receiver) = mpsc::unbounded_channel();
                let lane = Lane {
                    index,
                    sink: Arc::clone(sink),
                    permits: Arc::clone(permits),
                    capabilities,
                    inbox: receiver,
                    reports: reports.clone(),
                    keys: HashMap::new(),
                    ready: VecDeque::new(),
                    retries: BinaryHeap::new(),
                    last: None,
                };
                tasks.spawn(lane.run());
                inbox
            })
            .collect();
        Self { inboxes, tasks }
    }

    pub fn dispatch(&self, pending: Pending) -> Result<(), LaneStopped> {
        let index = pending.outbound.order_key.lane(self.inboxes.len());
        let inbox = self.inboxes.get(index).ok_or(LaneStopped(index))?;
        inbox.send(pending).map_err(|_| LaneStopped(index))
    }

    pub async fn shutdown(mut self) {
        self.tasks.shutdown().await;
    }
}

#[derive(Debug)]
struct Key {
    queue: VecDeque<Pending>,
    backoff: Backoff,
    failing: bool,
}

struct Lane {
    index: usize,
    sink: Arc<dyn Sink>,
    permits: Arc<Semaphore>,
    capabilities: SinkCapabilities,
    inbox: mpsc::UnboundedReceiver<Pending>,
    reports: mpsc::UnboundedSender<Report>,
    keys: HashMap<OrderKeyId, Key>,
    ready: VecDeque<OrderKeyId>,
    retries: BinaryHeap<Reverse<(Instant, OrderKeyId)>>,
    last: Option<EventId>,
}

impl Lane {
    async fn run(mut self) {
        loop {
            while let Ok(pending) = self.inbox.try_recv() {
                if !self.accept(pending) {
                    return;
                }
            }
            self.promote_due_retries(Instant::now());
            let Some(deadline) = self.linger_deadline() else {
                if !self.wait_for_work().await {
                    return;
                }
                continue;
            };
            let (count, full) = self.plan_batch();
            if !full && Instant::now() < deadline {
                tokio::select! {
                    received = self.inbox.recv() => match received {
                        Some(pending) => {
                            if !self.accept(pending) {
                                return;
                            }
                        }
                        None => return,
                    },
                    () = tokio::time::sleep_until(deadline) => {}
                }
                continue;
            }
            self.send_batch(count).await;
        }
    }

    fn accept(&mut self, pending: Pending) -> bool {
        let id = pending.outbound.id;
        if let Some(previous) = self.last
            && id <= previous
        {
            let error = LaneError::OutOfOrder {
                lane: self.index,
                previous,
                id,
            };
            let _ = self.reports.send(Report::Fatal(error));
            return false;
        }
        self.last = Some(id);
        let key = pending.outbound.order_key;
        match self.keys.entry(key) {
            Entry::Occupied(mut entry) => entry.get_mut().queue.push_back(pending),
            Entry::Vacant(entry) => {
                entry.insert(Key {
                    queue: VecDeque::from([pending]),
                    backoff: Backoff::new(RETRY_BASE, RETRY_CAP),
                    failing: false,
                });
                self.make_ready(key);
            }
        }
        true
    }

    fn make_ready(&mut self, key: OrderKeyId) {
        let Some(head) = self.keys.get(&key).and_then(|state| state.queue.front()) else {
            return;
        };
        let bytes = head.outbound.encoded_len();
        if bytes > self.capabilities.max_message_bytes {
            tracing::error!(
                order_key = %key,
                id = %head.outbound.id,
                bytes,
                max_message_bytes = self.capabilities.max_message_bytes,
                "event exceeds the sink's message size; its order key is blocked"
            );
            return;
        }
        self.ready.push_back(key);
    }

    fn promote_due_retries(&mut self, now: Instant) {
        while let Some(Reverse((due, key))) = self.retries.peek().copied() {
            if due > now {
                break;
            }
            self.retries.pop();
            self.make_ready(key);
        }
    }

    fn linger_deadline(&self) -> Option<Instant> {
        let key = self.ready.front()?;
        let head = self.keys.get(key)?.queue.front()?;
        Some(head.arrived + LINGER)
    }

    fn plan_batch(&self) -> (usize, bool) {
        let limits = self.capabilities;
        let mut count = 0;
        let mut bytes = 0_usize;
        for key in &self.ready {
            let Some(head) = self.keys.get(key).and_then(|state| state.queue.front()) else {
                continue;
            };
            let size = head.outbound.encoded_len();
            if count == limits.max_batch_messages
                || (count > 0 && bytes.saturating_add(size) > limits.max_batch_bytes)
            {
                return (count, true);
            }
            count += 1;
            bytes = bytes.saturating_add(size);
        }
        (count, count >= limits.max_batch_messages)
    }

    async fn wait_for_work(&mut self) -> bool {
        let next_retry = self.retries.peek().map(|Reverse((due, _))| *due);
        let retry = async {
            match next_retry {
                Some(due) => tokio::time::sleep_until(due).await,
                None => std::future::pending().await,
            }
        };
        tokio::select! {
            received = self.inbox.recv() => match received {
                Some(pending) => self.accept(pending),
                None => false,
            },
            () = retry => true,
        }
    }

    async fn send_batch(&mut self, count: usize) {
        let mut keys = Vec::with_capacity(count);
        let mut batch = Vec::with_capacity(count);
        for key in self.ready.drain(..count) {
            if let Some(head) = self.keys.get(&key).and_then(|state| state.queue.front()) {
                keys.push(key);
                batch.push(head.outbound.clone());
            }
        }
        let outcomes = match self.permits.acquire().await {
            Ok(_permit) => self.sink.send(&batch).await,
            Err(_) => Vec::new(),
        };
        if outcomes.len() != batch.len() {
            tracing::error!(
                sent = batch.len(),
                outcomes = outcomes.len(),
                "the sink broke its contract of one outcome per message"
            );
        }
        let mut outcomes = outcomes.into_iter();
        for key in keys {
            let outcome = outcomes.next().unwrap_or_else(|| {
                Outcome::Retryable(SinkError("the sink returned no outcome".to_owned()))
            });
            self.complete(key, &outcome);
        }
    }

    fn complete(&mut self, key: OrderKeyId, outcome: &Outcome) {
        let Some(state) = self.keys.get_mut(&key) else {
            return;
        };
        match outcome {
            Outcome::Delivered => {
                let Some(head) = state.queue.pop_front() else {
                    return;
                };
                if let Ok(settled) = head.ticket.settle(outcome) {
                    let _ = self.reports.send(Report::Settled(settled));
                }
                if state.queue.is_empty() {
                    self.keys.remove(&key);
                } else {
                    state.backoff.reset();
                    state.failing = false;
                    self.make_ready(key);
                }
            }
            Outcome::Retryable(error) => {
                let delay = state.backoff.next_delay();
                let id = state.queue.front().map(|head| head.outbound.id);
                if state.failing {
                    tracing::debug!(order_key = %key, ?id, %error, ?delay, "delivery failed again; retrying");
                } else {
                    tracing::warn!(order_key = %key, ?id, %error, ?delay, "delivery failed; retrying");
                }
                state.failing = true;
                self.retries.push(Reverse((Instant::now() + delay, key)));
            }
            Outcome::Terminal(error) => {
                let id = state.queue.front().map(|head| head.outbound.id);
                tracing::error!(
                    order_key = %key,
                    ?id,
                    %error,
                    "the sink rejected the event for good; its order key is blocked"
                );
            }
        }
    }
}

pub async fn run_session(
    config: &SessionConfig,
    provider: &dyn ConnectionProvider,
    sink: &Arc<dyn Sink>,
    shutdown: &CancellationToken,
) -> Result<(), SessionError> {
    let params = provider.params().await?;
    let control = connect_control(&params).await?;
    let start = catalog::slot_confirmed_flush(control.client(), &config.slot)
        .await?
        .ok_or_else(|| SessionError::SlotMissing(config.slot.clone()))?;
    for (schema, table) in
        catalog::tables_without_full_identity(control.client(), &config.publication).await?
    {
        tracing::warn!(%schema, %table, "published table does not use REPLICA IDENTITY FULL");
    }
    let mut stream = ReplicationStream::start(replication_config(&params, config, start).await?)
        .await
        .map_err(|error| stream_fault(error, start))?;
    let (reports, mut settled) = mpsc::unbounded_channel();
    let permits = Arc::new(Semaphore::new(config.sink_concurrency.max(1)));
    let mut session = Session {
        control: &control,
        types: TypeResolver::new(),
        relations: HashMap::new(),
        builder: Builder::new(config.pipeline.clone()),
        ack: AckTracker::new(start),
        lanes: Lanes::spawn(config.lanes, sink, &permits, &reports),
        order_by: &config.order_by,
        attribute_columns: &config.attribute_columns,
    };
    drop(reports);
    session
        .stream(&mut stream, &mut settled, shutdown, start)
        .await?;
    session.drain(&stream, &mut settled).await?;
    session.lanes.shutdown().await;
    if let Err(error) = stream.stop().await {
        tracing::warn!(%error, "replication stream did not stop cleanly");
    }
    Ok(())
}

fn next_event(
    received: Result<Option<ReplicationEvent>, ReplicationError>,
    position: &mut Lsn,
) -> Result<ReplicationEvent, SessionError> {
    let event = received
        .map_err(|error| stream_fault(error, *position))?
        .ok_or(SessionError::StreamEnded)?;
    if let ReplicationEvent::XLogData { wal_start, .. } = &event {
        *position = *wal_start;
    }
    Ok(event)
}

        other => SessionError::Replication(other),

struct Session<'a> {
    control: &'a ControlConnection,
    types: TypeResolver,
    relations: HashMap<u32, RelationInfo>,
    builder: Builder,
    ack: AckTracker,
    lanes: Lanes,
    order_by: &'a OrderBy,
    attribute_columns: &'a [String],
}

impl Session<'_> {
    async fn stream(
        &mut self,
        stream: &mut ReplicationStream,
        settled: &mut mpsc::UnboundedReceiver<Report>,
        shutdown: &CancellationToken,
        start: Lsn,
    ) -> Result<(), SessionError> {
        let mut position = start;
        loop {
            tokio::select! {
                biased;
                () = shutdown.cancelled() => return Ok(()),
                report = settled.recv() => self.report(report, stream)?,
                received = stream.recv() => {
                    let event = next_event(received, &mut position)?;
                    let Some(handled) = shutdown.run_until_cancelled(self.handle(event)).await else {
                        return Ok(());
                    };
                    if let Some(lsn) = handled? {
                        stream.confirm(lsn);
                    }
                }
            }
        }
    }

    async fn drain(
        &mut self,
        stream: &ReplicationStream,
        settled: &mut mpsc::UnboundedReceiver<Report>,
    ) -> Result<(), SessionError> {
        let settle_all = async {
            while self.ack.inflight_events() > 0 {
                self.report(settled.recv().await, stream)?;
            }
            Ok(())
        };
        if let Ok(result) = tokio::time::timeout(DRAIN_TIMEOUT, settle_all).await {
            return result;
        }
        tracing::warn!(
            unsettled = self.ack.inflight_events(),
            timeout_ms = DRAIN_TIMEOUT.as_millis(),
            "events still in flight after the drain timeout will replay"
        );
        Ok(())
    }

    fn report(
        &mut self,
        report: Option<Report>,
        stream: &ReplicationStream,
    ) -> Result<(), SessionError> {
        match report {
            Some(Report::Settled(settled)) => {
                stream.confirm(self.ack.settle(settled)?);
                Ok(())
            }
            Some(Report::Fatal(error)) => Err(error.into()),
            None => Err(SessionError::LanesStopped),
        }
    }

    async fn handle(&mut self, event: ReplicationEvent) -> Result<Option<Lsn>, SessionError> {
        match event {
            ReplicationEvent::XLogData {
                wal_start, data, ..
            } => self.message(wal_start, &data).await,
            ReplicationEvent::KeepAlive { wal_end } => Ok(Some(self.ack.keepalive(wal_end))),
        }
    }

    async fn message(&mut self, wal_start: Lsn, data: &[u8]) -> Result<Option<Lsn>, SessionError> {
        let message = decode(data).map_err(|source| SessionError::Decode { wal_start, source })?;
        let build_error = |source| SessionError::Build { wal_start, source };
        let built = match message {
            LogicalMessage::Begin(begin) => {
                self.builder
                    .begin(begin.final_lsn, begin.commit_ts)
                    .map_err(build_error)?;
                self.ack.begin()?;
                tracing::debug!(xid = begin.xid, commit_lsn = %begin.final_lsn, "transaction");
                return Ok(None);
            }
            LogicalMessage::Commit(commit) => {
                self.builder.commit().map_err(build_error)?;
                return Ok(Some(self.ack.commit(commit.end_lsn)?));
            }
            LogicalMessage::Relation(relation) => {
                self.relation(relation).await?;
                return Ok(None);
            }
            LogicalMessage::Type(_) | LogicalMessage::Origin(_) => return Ok(None),
            LogicalMessage::Insert(insert) => {
                let relation = known(&self.relations, wal_start, insert.relation_oid)?;
                self.builder
                    .insert(relation, &insert)
                    .map_err(build_error)?
            }
            LogicalMessage::Update(update) => {
                let relation = known(&self.relations, wal_start, update.relation_oid)?;
                self.builder
                    .update(relation, &update)
                    .map_err(build_error)?
            }
            LogicalMessage::Delete(delete) => {
                let relation = known(&self.relations, wal_start, delete.relation_oid)?;
                self.builder
                    .delete(relation, &delete)
                    .map_err(build_error)?
            }
            LogicalMessage::Truncate(truncate) => {
                for oid in truncate.relation_oids {
                    let relation = known(&self.relations, wal_start, oid)?;
                    let event = self.builder.truncate(relation).map_err(build_error)?;
                    self.emit(&event)?;
                }
                return Ok(None);
            }
        };
        self.emit(&built)?;
        Ok(None)
    }

    async fn relation(&mut self, relation: Relation) -> Result<(), SessionError> {
        let client = self.control.client();
        let mut columns = Vec::with_capacity(relation.columns.len());
        for column in relation.columns {
            let kind = self.types.resolve(client, column.type_oid).await?;
            columns.push(ColumnInfo {
                name: column.name,
                type_oid: column.type_oid,
                kind,
                is_identity: column.is_key,
            });
        }
        let key_columns = catalog::key_columns(client, relation.oid).await?;
        let schema = if relation.namespace.is_empty() {
            "pg_catalog".to_owned()
        } else {
            relation.namespace
        };
        let info = RelationInfo {
            oid: relation.oid,
            schema,
            table: relation.name,
            columns,
            key_columns,
        };
        self.relations.insert(relation.oid, info);
        Ok(())
    }

    fn emit(&mut self, built: &Built) -> Result<(), SessionError> {
        for fallback in &built.fallbacks {
            tracing::error!(
                id = %built.envelope.id,
                column = %fallback.column,
                type_oid = fallback.type_oid,
                "value fell back to its text form"
            );
        }
        let key = order_key(self.order_by, &built.envelope);
        let outbound = Outbound::encode(&built.envelope, key, self.attribute_columns)?;
        let bytes = u64::try_from(outbound.body.len()).unwrap_or(u64::MAX);
        let ticket = self.ack.track(bytes)?;
        self.lanes.dispatch(Pending {
            outbound,
            ticket,
            arrived: Instant::now(),
        })?;
        Ok(())
    }
}

fn known(
    relations: &HashMap<u32, RelationInfo>,
    wal_start: Lsn,
    oid: u32,
) -> Result<&RelationInfo, SessionError> {
    relations
        .get(&oid)
        .ok_or(SessionError::UnknownRelation { wal_start, oid })
}

fn de_string_list<'de, D: Deserializer<'de>>(deserializer: D) -> Result<Vec<String>, D::Error> {
    #[derive(Deserialize)]
    #[serde(untagged)]
    enum ListField {
        List(Vec<StringField>),
        Text(StringField),
    }

    Ok(match ListField::deserialize(deserializer)? {
        ListField::List(items) => items.into_iter().map(|item| item.0).collect(),
        ListField::Text(text) => text
            .0
            .split(',')
            .map(str::trim)
            .filter(|item| !item.is_empty())
            .map(str::to_owned)
            .collect(),
    })
}

fn de_fair_queue_group<'de, D: Deserializer<'de>>(

    let Some(text) = de_opt_string(deserializer)? else {
        return Ok(None);
    };
    match text.strip_prefix("column:") {
        Some(column) if !column.is_empty() => Ok(Some(column.to_owned())),
        _ => Err(de::Error::custom(format!(
            "fair_queue_group {text:?} must be column:<name>"

    }

pub async fn preflight(sink: &dyn Sink, shutdown: &CancellationToken) -> bool {
    let mut backoff = Backoff::default();
    loop {
        let Some(result) = shutdown.run_until_cancelled(sink.preflight()).await else {
            return false;
        };
        let error = match result {
            Ok(()) => return true,
            Err(error) => error,
        };
        let delay = backoff.next_delay();
        let delay_ms = u64::try_from(delay.as_millis()).unwrap_or(u64::MAX);
        tracing::warn!(%error, delay_ms, "sink preflight failed; retrying");
        if !sleep_unless_cancelled(delay, shutdown).await {
            return false;
        }
    }
}

async fn sleep_unless_cancelled(delay: Duration, shutdown: &CancellationToken) -> bool {
    tokio::select! {
        biased;
        () = shutdown.cancelled() => false,
        () = tokio::time::sleep(delay) => true,
    }
}

fn init_logging(sink: &SinkConfig) {
    let filter = EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new("info"));
    let builder = tracing_subscriber::fmt().json().with_env_filter(filter);
    match sink {
        SinkConfig::Stdout => builder.with_writer(std::io::stderr).init(),
        SinkConfig::Discard | SinkConfig::Sns(_) => builder.with_writer(std::io::stdout).init(),
    }

async fn run(config: Config) -> anyhow::Result<()> {
    let shutdown = CancellationToken::new();
    let terminate = signal(SignalKind::terminate()).context("cannot listen for SIGTERM")?;
    let interrupt = signal(SignalKind::interrupt()).context("cannot listen for SIGINT")?;
    tokio::spawn(watch_signals(terminate, interrupt, shutdown.clone()));
    tracing::info!(pipeline = %config.pipeline, slot = %config.source.slot, "pg-cdc starting");
    let Some(provider) = shutdown
        .run_until_cancelled(Box::pin(provider(&config.source)))
        .await
    else {
        tracing::info!("pg-cdc stopped cleanly");
        return Ok(());
    };
    let Some(sink) = shutdown
        .run_until_cancelled(Box::pin(sink(&config.sink)))
        .await
    else {
        tracing::info!("pg-cdc stopped cleanly");
        return Ok(());
    };
    if !preflight(sink.as_ref(), &shutdown).await {
        tracing::info!("pg-cdc stopped cleanly");
        return Ok(());
    }
    let session = SessionConfig {
        pipeline: config.pipeline.clone(),
        slot: config.source.slot.clone(),
        publication: config.source.publication.clone(),
        status_interval: config.source.status_interval,
        buffer: REPLICATION_BUFFER,
        order_by: config.delivery.order_by.clone(),
        lanes: config.delivery.lanes,
        sink_concurrency: config.sink.max_concurrency(),
        attribute_columns: config.sink.attribute_columns().to_vec(),
        max_inflight_bytes: config.delivery.max_inflight_bytes,
    };
    let mut live = LiveSession {
        config: &session,
        provider: provider.as_ref(),
        sink: &sink,
        shutdown: &shutdown,
    };
    supervise(&mut live, &shutdown)
        .await
        .context("replication stopped")?;
    tracing::info!("pg-cdc stopped cleanly");
    Ok(())
}

async fn sink(config: &SinkConfig) -> Arc<dyn Sink> {

                sns.topic_arn.clone(),
                sns.region.clone(),
                sns.fair_queue_group.clone(),
            )
            .await,
        ),
    }
}
